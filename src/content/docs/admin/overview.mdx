This guide is for the people who run Catalyst itself: installing the panel,
adding nodes, and keeping the whole thing healthy.

## Path for a new operator

1. Check [requirements](/admin/requirements/) — OS, CPU, memory, disk, network.
2. [Install Catalyst](/admin/installation/) with the released installer — one
   `curl` command on a root shell.
3. Complete [first-time setup](/admin/first-time-setup/) — admin account, panel
   name, public URL, and appearance.
4. [Install a node](/admin/nodes/installing/) and [register it](/admin/nodes/registering/)
   — [nodes overview](/admin/nodes/overview/) explains what they do.
5. [Create users and roles](/admin/users/) for your staff.
6. Import or create [templates](/admin/templates/), then make the first server.
7. [Install plugins](/admin/plugins/) if you need extensions.
