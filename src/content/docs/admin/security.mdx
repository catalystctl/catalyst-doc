## Panel

- Serve everything over HTTPS with valid certificates ([networking](/admin/networking/)).
- Keep the panel updated — security fixes ship in releases ([updating](/admin/updating/)).
- Restrict who can reach the admin UI by network (VPN, allowlist) in addition
  to passwords.
- Never expose the database or Redis ports to the internet. The bundled compose
  stack publishes PostgreSQL on `127.0.0.1` only and leaves Redis internal to
  the Docker network by default.

## Accounts and access

- Few admins, named accounts, prompt offboarding ([users](/admin/users/)).
- Least-privilege [roles](/admin/roles/) for staff; scoped
  [API keys](/api/authentication/) for integrations.
- Treat node API keys and backup encryption keys as crown jewels: generated
  randomly, stored once, rotated on suspicion.

## Security settings

Open **Admin → Security**. Settings take effect when you select **Save** in
each section.

- **Rate Limits** — per-category request and message budgets: **Auth requests**,
  **File operations**, **Console input**, **Console output lines / sec**,
  **Console output bytes / sec**, **Agent messages / sec**, **Agent metrics /
  sec**, **Server metrics / sec**, and **Max buffer (MB)**. Each rate limit has
  a count and a time window (second, minute, hour, day, or month).
- **Email Verification** — **Require verified email before sign-in**.
- **Lockout Policy** — **Max attempts**, **Window (minutes)**, **Duration
  (minutes)**, and **Audit retention (days)**. Failed sign-ins lock out per
  email + IP combination.
- **File Uploads** — **Tunnel requests**, **Max upload size (MB)** (up to
  10240 MB), **Max pending per node**, and **Max concurrent (agent)**. The
  upload size applies to the file browser and SFTP on every node; **Max
  concurrent** needs an agent restart to take effect.
- **Auth Lockouts** — recent lockout entries with a **Clear lockout** action.

Registrations are governed by the `REGISTRATION_ENABLED` environment variable
and the stored security setting ([configuration](/admin/configuration/)).

## Panel MCP endpoint (AI assistants)

The panel can expose itself as a Streamable HTTP MCP server so an AI
assistant can manage servers, nodes, users, and the rest of the panel API
with the same permissions as the API key it is given. It is **disabled by
default**.

Prerequisites: an admin account, and a panel API key for the assistant
(Profile > API keys) scoped to only the permissions it needs.

1. In **Admin → Security**, find the **Panel MCP access** section.
2. Turn on **Enable panel MCP endpoint**. A confirmation dialog explains the
   risks; select **I understand, enable anyway**. It takes effect immediately —
   no restart.
3. Optionally set the **Tool budget (per key / min)** (10–5000, default 300).
   The **MCP endpoint** field shows the exact URL to copy —
   `https://panel.example.com/api/mcp`.
4. Select **Save**.
5. Point the MCP client at that endpoint with the dedicated API key as the
   Bearer credential.
6. Verify with a read-only call first (for example `whoami`), then try one
   `list_servers` before granting broader scopes.

:::caution
Destructive tools (delete, reinstall, restore, ban, …) run as soon as the
assistant calls them with `confirm: true`. Use a least-privilege key, keep
the per-minute tool budget low, and revoke the key when the job is done.
:::

Session cookies are never accepted on this endpoint, so it cannot be
abused from a browser session. Every tool call is permission-checked and
audit-logged exactly like direct API use.

## Nodes

- Only the agent's required ports plus game allocations listen publicly.
- Apply OS and runtime updates on a rhythm; nodes run untrusted game code and
  third-party mods by design.
- Review [imported egg install scripts](/admin/importing-eggs/) — they are the
  largest untrusted-code surface in normal operation.

## Report a vulnerability

Do not open a public issue for a suspected security bug. See `SECURITY.md` in
the main Catalyst repository for the private reporting channel, and expect
coordinated disclosure: report, fix window, then public advisory.
