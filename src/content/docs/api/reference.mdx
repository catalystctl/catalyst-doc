This reference is **generated** from the backend's route definitions
(`catalyst-backend/scripts/export-openapi.ts` → `api/openapi.json`), so it
tracks the code instead of drifting from it. Each operation carries an
`x-catalyst.source` pointer back to the route file and line, plus the
permission guards it enforces.

<ScalarReference />

:::note
The generated contract covers the REST endpoints. The long-lived SSE streams
(`/api/servers/:id/console/stream`, `/events`, `/metrics/stream`) are not listed
in it — see [Realtime events](/api/websockets/) for those.
:::

:::note
The viewer loads from a CDN with JavaScript enabled. Offline or script-blocked
readers can use the raw [openapi.json](/openapi.json) directly with any
OpenAPI tool.
:::
