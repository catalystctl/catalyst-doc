Your game client connects directly to the node running your server — the panel
is for management, not for play.

## Prerequisites

- A server you can access, with its address shown in the header.
- A node address the panel can show — the node's public address or hostname,
  or the server's primary IP. If the header shows `n/a`, ask your administrator.
- The game client installed on the machine you play from.

## Find your address

1. Open your server. The address is shown in the header next to the server name
   as `IP:port`, for example `203.0.113.10:25565`.
2. Click the address to copy it — the panel confirms with a **Copied address**
   message.
3. If the header shows `n/a`, the panel has no host address for the server's
   node. Ask your administrator to set one before players can join.
4. Additional allocations for extra ports (query, RCON, voice, Bedrock) are
   listed under **Admin → Ports**. That tab needs administrator access; if you
   do not see it, ask your administrator. You may not be allowed to add or
   remove allocations yourself.

Some hosts put a reverse proxy or custom hostname in front of game ports. If
your host gave you a hostname such as `play.example.com`, use that instead of
the raw IP.

## Connect from the game

- **Minecraft (Java):** Multiplayer → Add Server → paste the address.
- **Minecraft (Bedrock):** Play → Servers → Add Server (check the port — Bedrock
  defaults differ from Java).
- **Other games:** use the address shown in the server header with the game's
  normal server browser or `connect` command.

## If you cannot connect

1. Confirm the server status in the header reads **Running**.
2. Confirm you are using the right IP **and** port. The port matters unless your
   host told you it is optional.
3. Check the console for errors during startup — a crashed server accepts no connections.
4. See [server issues](/troubleshooting/server/) and
   [networking issues](/troubleshooting/networking/).
