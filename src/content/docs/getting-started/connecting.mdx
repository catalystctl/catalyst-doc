Your game client connects directly to the node running your server — the panel is
for management, not for play.

## Prerequisites

- A server you can access.
- The game client installed on the machine you play from.

## Find your address

1. Open your server. The header shows the address next to the server name as
   `IP:port`, for example `203.0.113.10:25565`.
2. Click the address to copy it — the panel confirms with a **Copied address**
   message.
3. If it shows `n/a`, the panel has no host address for the server's node. Ask
   your administrator to set one before players can join.
4. Extra ports (query, RCON, voice, Bedrock) are listed under **Admin → Ports**.
   The tab opens for `server.delete` (owners) or `admin.write`; changing
   allocations needs `server.network`, which a subuser may not have.

Some hosts put a reverse proxy or custom hostname in front of game ports. If your
host gave you a hostname such as `play.example.com`, use that instead of the raw
IP.

## Connect from the game

- **Minecraft (Java):** Multiplayer → Add Server → paste the address.
- **Minecraft (Bedrock):** Play → Servers → Add Server (check the port — Bedrock
  defaults differ from Java).
- **Other games:** use the address with the game's normal server browser or
  `connect` command.

## If you cannot connect

1. Confirm the status in the header reads **Running**.
2. Confirm you are using the right IP **and** port.
3. Check the console for errors during startup — a crashed server accepts no
   connections.
4. See [server issues](/troubleshooting/server/) and
   [networking issues](/troubleshooting/networking/).
