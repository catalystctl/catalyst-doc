This guide creates a working Minecraft (Paper) server. The same steps apply to
any game: pick a template, choose resources and an allocation, create, install,
start.

## Prerequisites

- An account on a Catalyst panel (your host or administrator provides this).
- Permission to create servers. If the **New server** button is missing, ask
  your administrator for the `server.create` permission or access to a node.
- A node with free memory, disk, and at least one free allocation. If creation
  fails, ask your administrator — see [server issues](/troubleshooting/server/).

## 1. Create the server

1. Open **Servers** and select **New server**. The **Create new server** dialog
   opens on the **Details** step, with a step rail across the top:
   **Details → Resources → Network → Startup**.
2. On **Details**, enter a **Server Name** you will recognize, for example
   `Survival SMP`. **Description** is optional.
3. Choose the **Template** — the searchable list of installed games. For
   Minecraft: Java Edition, pick **Minecraft Server (Universal)**. Its
   **SERVER_TYPE** variable decides the server software and defaults to Paper —
   you will confirm it on the **Startup** step. If the template offers an
   **Image Variant**, leave it on **Use default image** unless you need a
   specific Java runtime.
4. Choose the **Node** to run it on (usually there is only one).
5. Select **Next** to open **Resources**. **Memory (MB)** and **Disk (MB)** are
   prefilled from the template and **CPU Cores** defaults to `1`; accept them
   unless you know you need more. **Swap (MB)**, **Backup (MB)**, and
   **Database Allocation** can stay blank to use the provider defaults.
6. Select **Next** to open **Network**. Leave **Network Mode** on
   **Host (port mapping)** — the usual choice. Under **Primary Allocation**,
   pick an **Allocation** (IP + port) for players to join through. **Primary
   Port** fills in from that allocation automatically. (Choose **Macvlan** only
   if your administrator told you to.)
7. Select **Next** to open **Startup**. These are the template's
   **Environment Variables**; the defaults are a good starting point. Anything
   marked with a red `*` is required. For the Minecraft template, leave
   **SERVER_TYPE** on `paper`, and if you like, tick the **EULA** checkbox to
   accept the Minecraft licence up front (otherwise Catalyst asks after
   install).
8. Select **Create server**. Catalyst creates the server and starts the install
   automatically, then opens its **Console**. Installation can take a few
   minutes — watch the output in the **Console** tab.

:::caution
Creating a server allocates real resources on the node. Delete test servers you
no longer need so they stop consuming memory and disk.
:::

## 2. Accept the Minecraft EULA

Minecraft servers refuse to run until the EULA is accepted. If you did not tick
the **EULA** checkbox during creation, Catalyst asks for it in the panel, so you
do not edit any files:

1. When installation finishes, or when you select **Start** in the server
   header, the **Minecraft EULA** dialog appears and the server waits.
2. Scroll to the bottom of the licence — the **I Agree** button enables once you
   reach the end.
3. Select **I Agree**. Catalyst writes the acceptance for you and starts the
   server. Select **Decline** to leave the server stopped.

## 3. Join the server

1. If the server is not already running, select **Start** in the header and wait
   for the console to print the `Done!` line.
2. Click the address shown in the server header (for example
   `203.0.113.10:25565`) to copy it. See
   [Find your address](/getting-started/connecting/) if it is not visible.
3. In Minecraft, use **Multiplayer → Add Server** and paste the address.
