## Install the panel

On a fresh Linux host, run this from a root shell. The installer installs Docker
when needed, writes a configured `.env` with generated secrets, and leaves the
stack ready to start:

```bash
curl -fsSL https://github.com/catalystctl/catalyst/releases/latest/download/install.sh | sudo bash
```

Then [bring the stack up and finish setup](/admin/installation/). Check
[system requirements](/admin/requirements/) first, and add a
[node](/admin/nodes/installing/) before you create game servers. To pin a
release, replace `latest` in the URL with a release tag; the installer can also
[verify its own checksum](/admin/installation/).
