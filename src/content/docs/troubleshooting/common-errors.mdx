This page maps what you **see** to what to do. The panel and API attach a stable
`code` to most errors — look yours up in [API errors](/api/errors/) for the HTTP
status and whether it is safe to retry. Branch on the `code`, never on the
message: messages are localized and may change.

## Symptom guide

| What you see | Cause | Fix |
| --- | --- | --- |
| "You do not have permission to perform this action." (`PERMISSION_DENIED`) | Signed in, but not allowed. | Check your role or subuser grants ([authorization](/api/authorization/), [subusers](/users/subusers/)). |
| "Some of the provided values are invalid." (`VALIDATION_ERROR`) | A field was rejected. | Fix the highlighted field; for API calls read `details` for the offending fields. |
| "That value is already taken." (`CONFLICT`) | A unique value (usually the name) exists. | Rename, or delete the conflicting resource first. |
| "The requested resource could not be found." (`NOT_FOUND`) | It was deleted, or it is hidden from your account. | Check the ID and confirm it still exists. |
| "Too many requests. Please wait a moment and try again." (`RATE_LIMITED`) | You are over a rate limit. | Back off, stop polling ([rate limits](/api/rate-limits/)). |
| "The node does not have enough resources for this action." (`INSUFFICIENT_RESOURCES`) | The node lacks memory, CPU, disk, or free allocations. | Free capacity or ask the administrator for a bigger node. |
| `Port {{port}} is already in use on this node.` (`PORT_ALREADY_IN_USE`) | Two servers claim the same allocation. | [Server issues](/troubleshooting/server/) — free or reassign the port. |
| "The server must be stopped for this action (current state: …)." (`SERVER_NOT_STOPPED`) | The action needs the server off. | **Stop** the server, then retry. |
| "The node is offline and cannot accept this action." (`NODE_OFFLINE`) | The node's agent is not reachable. | [Node issues](/troubleshooting/node/). |
| "The agent did not respond in time." (`AGENT_TIMEOUT`) | The agent did not answer within the request timeout. | Retry once, then check node load and free disk. |
| "This server is suspended." (`SERVER_SUSPENDED`) | Suspension is enforced on the panel. | Ask the administrator to unsuspend it. |
| "This account is temporarily locked after too many failed sign-in attempts." (`ACCOUNT_LOCKED`) | Sign-in lockout. | Wait for the lockout to expire, or ask an administrator. |
| "This account has been suspended." (`ACCOUNT_BANNED`) | The account is banned. | Ask an administrator. |
| Minecraft **Minecraft EULA** dialog | The EULA is not accepted yet. | Select **I Agree**, then start the server ([first server](/getting-started/first-server/)). |
| SFTP client reports "authentication failed" | Stale or mistyped credentials. | Copy fresh credentials from the **SFTP** tab ([SFTP](/users/sftp/)). |

If your message is not here, open **Admin → System Errors** to see the persisted
exception, or capture a [diagnostics bundle](/troubleshooting/diagnostics-bundle/).
