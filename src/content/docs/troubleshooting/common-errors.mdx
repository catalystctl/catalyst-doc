This page maps what you **see** to what to do. The panel and API attach a
stable `code` to most errors — look yours up in
[API errors](/api/errors/) for the HTTP status, meaning, and whether it is
safe to retry. Branch on the `code`, never on the message: messages are
localized and may change.

## Symptom guide

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| "Insufficient permissions" | Logged in, but not allowed. | Check your role/subuser grants ([authorization](/api/authorization/), [subusers](/users/subusers/)). |
| Form rejected, "Missing required fields" | The request or form was incomplete. | Fill the highlighted fields; for API calls compare against the [reference](/api/reference/). |
| "Not found" | No such thing, or hidden from your account. | Check the ID/UUID; confirm it was not deleted. |
| "Already exists" / duplicate name | A conflicting resource exists. | Rename, or stop/delete the conflicting resource first. |
| "Too many requests" | You are over the rate limit. | Slow down, back off, stop polling ([rate limits](/api/rate-limits/)). |
| "Insufficient memory/disk/ports" | The node lacks capacity. | Free capacity or ask the administrator for a bigger node. |
| "Port N is already in use on this node" (`PORT_ALREADY_IN_USE`) | Two servers claim the same allocation. | [Server issues](/troubleshooting/server/) — free or reassign the port. |
| "Server must be stopped ..." (`SERVER_NOT_STOPPED`) | The action needs the server off. | **Stop** the server, then retry — restore and similar actions require it. |
| "Node offline" / agent unreachable | The node's agent is not reachable. | Check the agent on the node ([node issues](/troubleshooting/node/)). |
| Minecraft **Minecraft EULA** prompt | The EULA is not accepted yet. | In the **Console**, select **I Agree**, then start the server ([first server](/getting-started/first-server/)). |
| SFTP "authentication failed" | Stale or mistyped credentials. | Copy fresh credentials from the SFTP tab ([SFTP](/users/sftp/)). |
| Setup wizard missing on fresh install | Setup already ran, or the backend is still migrating. | Sign in; if erroring, check container logs ([panel issues](/troubleshooting/panel/)). |

If your message is not here, open **Admin → System Errors** to see the persisted
exception, or capture a [diagnostics bundle](/troubleshooting/diagnostics-bundle/).
You can also search the page text in the main Catalyst repository issues — and
consider contributing the fix back to this page (see
[docs contributor guide](/contributing/docs/)).
