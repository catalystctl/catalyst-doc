When something breaks, start with the layer that owns the symptom:

| Symptom | Go to |
| --- | --- |
| One game server crashes, will not start, or misbehaves | [Server issues](/troubleshooting/server/) |
| A whole node is unreachable or all its servers suffer | [Node issues](/troubleshooting/node/) |
| The panel itself errors, logins fail, pages break | [Panel issues](/troubleshooting/panel/) |
| Players cannot connect but everything looks green | [Networking issues](/troubleshooting/networking/) |
| A specific error message | [Common errors](/troubleshooting/common-errors/) |

## How to report a problem well

Whether you ask your administrator, your host, or the community, include:

1. **What you expected** vs. **what happened** (one sentence each).
2. **The exact error text** — copy, do not paraphrase. Codes from
   [common errors](/troubleshooting/common-errors/) speed everything up.
3. **When** it started and **what changed** just before (updates, new mods,
   config edits, new server).
4. **Scope**: one server, all servers on a node, or the whole panel.

"The server is broken" takes five follow-up questions. The four facts above
usually get an answer in one round.
