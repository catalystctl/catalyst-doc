The **Activity** tab (titled **Activity Log**) is an audit trail for your
server: power actions, file changes, backup restores, subuser changes, and
similar events, each stamped with who did it and when. Entries are a flat list,
newest first, paged 25 at a time. An **Updated …** stamp in the tab header says
when the list last refreshed — hover it for the exact time — and a failed
refresh keeps the entries already on screen, with the error shown above them.

## Read an entry

Each row shows the action, who performed it, the time, and a summary of the
important fields — node, port, or the before/after values a power action
changed. Expand a row's **Details** to see every recorded field. **System**
marks an action the panel took on its own (for example a task or a crash
recovery) rather than one a person triggered.

## Use it for

- **"Who stopped the server?"** — scan for power events and check the actor.
- **"What changed before it broke?"** — correlate the first failure with the
  last file or config change.
- **Subuser oversight** — confirm helpers only touch what they should.

## Limits

- Activity records panel actions, not in-game events. For gameplay history, use
  your game's own logs (see [console](/users/console/)).
- Retention is finite and set by the administrator — 90 days by default. If you
  need a permanent record for a dispute, ask for an audit-log export before it
  ages out.
- If an expected entry is missing, the action may have happened outside the
  panel (direct node access) — ask your administrator.
