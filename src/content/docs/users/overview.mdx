Open a server and you will see its management tabs. Each tab has its own guide:

| Tab | What it is for |
| --- | --- |
| [Console](/users/console/) | Live logs, commands, start/stop/restart. |
| [Power](/users/power/) | Start, stop, restart, and kill a stuck server. |
| [Files](/users/files/) | Browse, edit, upload, download, archive. |
| [SFTP](/users/sftp/) | Connect with FileZilla or WinSCP for big transfers. |
| [Backups](/users/backups/) | Create and restore snapshots of your files. |
| [Databases](/users/databases/) | Databases for plugins and mods. |
| [Tasks](/users/tasks/) | Scheduled restarts, backups, and commands. |
| [Networking](/users/networking/) | Allocations (IP + port) for players. |
| [Startup](/users/startup/) | Startup command and variables. |
| [Users](/users/subusers/) | Give friends limited access. |
| [Activity](/users/activity/) | Who did what, and when. |
| [Metrics & Alerts](/users/metrics/) | CPU, memory, disk graphs and alerts. |
| [Mods & Plugins](/users/mods-plugins/) | One-click mod and plugin managers. |
| [Reinstalling](/users/reinstalling/) | Start over without losing everything. |

What you see depends on your permissions. Owners see everything; subusers only
see the tabs the owner enabled. If a tab is missing, ask the server owner —
nothing is broken.
