Reinstalling replaces your server files with a fresh copy from its template.
Use it when an installation is damaged beyond easy repair — corrupted jars,
mangled configs after a bad edit, or a version jump you would rather do cleanly.

## Before you reinstall

1. [Create a backup](/users/backups/) and wait for it to finish.
2. Download anything the backup might not cover that you care about (or verify
   the backup completed — do not skip this).
3. Tell your players: the server will be offline and the world may reset.

## Reinstall

1. Open your server's settings/admin area and choose **Reinstall**.
2. Confirm. The panel wipes the server directory and re-runs the template's
   install script.
3. Wait for installation to finish in the console, re-apply your settings
   (EULA, configs, plugins), and start the server.

::: caution
Reinstalling deletes current files. It is not an upgrade path for worlds you
want to keep unless you restore them afterwards from the backup.
:::

## Alternatives to consider first

- One broken config? Revert that file instead of wiping everything.
- Boot loop after a variable change? Revert the variable ([startup](/users/startup/)).
- Just want a second world? Ask your administrator for another server instead.
